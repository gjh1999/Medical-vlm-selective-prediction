01 / 方向研判

四条路线，四种取舍。

以下是导师判断与待验证假设，
不是已经证实的研究空白。

候选路线低成本起步方式数据准备主要发表障碍博士主线潜力*
交互分割可靠性冻结 UNet、扰动提示Kvasir 可直接起步模拟交互与真实交互差距较好：标注效率与可靠性
跨模态异常校准复用 CLIP 适配权重BMAD 逐源确认同质化、正常/异常协议较好：跨域可靠性
支持集质量与预算UniverSeg 免训练推理检查预训练任务重叠通用检索基线很强取决于机制深度
医学 VLM 可靠决策缓存特征、校准头MedMNIST 可直接起步来源泄漏、已有校准方法较好：开放集与长尾

* 主观判断；以你对问题的兴趣、数据质量与初步证据为准，不是方向评分或录用概率。

暂不优先投入：从头训练百万级医学图文模型、完整 3D 基础模型预训练、没有现成合法特征的 WSI 全流程、依赖多卡的生成式医学推理训练。FOCUS、IMIS、SegMoTE 等仍值得读，是否选为起点取决于数据和资源条件。

03 / 数据先行

公开数据，是开题的硬条件。

不把“有论文”“有网盘”
自动等同于数据完整、许可清楚。

A公开入口较明确原站或作者直接发布；仍需遵守用途限制。
B混合授权 / 分源获取代码开放，原图、标注、权重不一定同许可。
C审核或协议访问可申请资源，不符合无等待获取条件。

A/B/C 是访问层级，不是法律意义上统一的“开源许可证”分类。本报告检查的是公开获取证据；未替你完成账号登录、授权审核和整包完整性校验。

重要协议细节：Kvasir-SEG 是病灶分割集，不能凭空生成真实正常图像来评价图像级异常检测。MedMNIST 是分类资源，不能用于像素异常定位。没有病例 ID 的数据，至少做近重复与来源审计，并诚实说明患者级独立性未能完全确认。
04 / 最小验证

用两周决定，要不要继续。

这是开题试跑安排，
不是论文完成或录用时间表。

01—02 天

数据先过关

拿到原图和标签，保存来源、许可与校验和；检查正常负例、患者/视频划分、近重复、预训练重叠。无法获取数据就换候选资源，不先写模型。

03—05 天

建立可信基线

固定代码提交、权重和环境；跑公开权重及简单基线。先测小批次峰值显存与延迟，再决定是否训练。

06—10 天

只验证一个机制

固定数据预算、分辨率与评估协议；用三个预先选定的种子比较。开发用验证集，测试集到方案冻结后再评估。

11—14 天

查新与止损

补一个外部数据/模态和失败案例；若增益不稳定或简单基线已解释结果，记录负结果并调整问题。证据成立后，再安排完整对照与写作。

形成论文贡献，需要哪些证据？

  • 具体失败现象：不是先想一个模块再寻找应用。
  • 能被推翻的假设：明确什么结果说明方法不成立。
  • 公平对照：至少包含简单强基线、关键消融、预算匹配和多种子结果。
  • 外部验证：区分域内、跨设备、跨模态与真正未见任务。
  • 可复现材料：版本、划分、命令、权重、输出和失败案例。

先形成小论文，再积累博士主线

短期可以从一个明确失效问题切入；长期要有统一问题意识，例如“有限监督下医学基础模型的可靠适应”。这只是可选的组织方式，你也可以根据第一轮证据选择其他主线。

报告中的方案仅是待查新的候选。没有完成同类文献排查前，不宣称“首次提出”；来源论文是学习与比较的锚点，不代表目标投稿会议或录用保证。
