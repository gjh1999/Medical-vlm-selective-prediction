# 在固定预算下选择追加皮肤镜的病灶

**导师初审，2026-11-18。** 否决以“决定哪些临床照片需要皮肤镜”作为论文创新。Mehta 等的 HOT 已用临床图表征与最近病种原型的距离做分诊，约 44% 的图像获推荐追加，论文还分别评价了患者和诊所划分。测试时有成本的医学检查选择也有更早的算法工作。保留一个可证伪的子问题：两张图有时让分类从对变错，只见临床图时能否预测追加后的净纠错数？ [HOT 原文，图 1 与表 S5](https://doi.org/10.1111/jdv.20551) · [Vivar 等的测试时特征采集研究](https://arxiv.org/abs/2003.14127)

**可用证据。** 从 MILK study team 发布的三张训练表实测，5,240 个病灶全部有一张临床近照和一张皮肤镜。已查三表均缺患者和中心标识。479 对的官方盲测集与训练集来自相同来源。可开展病灶级开发，患者级独立性和跨中心迁移需另外举证。许可标为 CC-BY-NC。原始数据的纳入偏向已活检或切除病灶，离线纠错数只能评价指定分类器。 [ISIC 数据发布](https://api.isic-archive.com/doi/milk10k/) · [官方挑战](https://challenge.isic-archive.com/landing/milk10k/) · [实测记录](实验记录.md)

## 下一次可推翻假设的比较

1. **冻结两种输出。** 在公开训练集内按病灶分组，先留出开发集，再在剩余部分交叉拟合。用相同的固定骨干产生只看临床图、看配对双图两种分类。训练路由器时用折外预测生成标签。令净纠错为“双图答对”减“单图答对”，同时记录纠正数、引入错误数和持平数。
2. **对齐信息和预算。** 主预算选开发病灶数的 25% 向下取整，另报告 10%、50% 曲线。每个策略恰选相同数量，按预先固定的哈希打破平分。比较随机、临床图置信度、最近类别原型距离、只用置信度拟合的净收益，以及用临床图冻结特征拟合的正则化净收益回归。原型距离是对 HOT 决策信号的对照，完整 HOT 如未复现，单独标注。看过两张图与真值的排序仅用于测量理论上限。
3. **测量范围。** 主终点为每 100 个候选病灶净纠正多少个分类，同时报告类别分解和配对区间。前置选择器只读取临床图；诊断属性、皮肤镜 MONET 分数、第二视图特征均隔离。划分前用历史 ID（如可获）、像素哈希和近重复人工复核连接同源病灶。已查三表缺少显式历史 ID 列，当前 MILK 与 HAM 图号交集为零只能排除同号图片。骨干训练名单不全时保留重叠未知标记。
4. **停题门槛。** 开发集主预算下，若离线最优排序较最强可部署简单基线每百例多纠正不足 1 例，停止方法开发。若有空间但净收益回归未稳定优于置信度和原型距离，保留失败分析。胜出仅放行第二来源验证，开展前先锁定可核查的患者分组。1 例/百例是本项目资源取舍，尚无临床效用估计。
