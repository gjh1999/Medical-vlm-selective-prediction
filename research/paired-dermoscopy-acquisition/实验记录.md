# 实验记录

## 2026-11-18 E00 配对与身份字段审计

**目的与环境。** 核对本地能否恢复 MILK10k 的两种视图，及其与已登记 HAM 图号的重合。准备机 Windows，Python 3.14.7 标准库，未读取影像或调用模型。

**输入与获取。** 只读 MILK study team 发布的训练元数据、模型输入表和诊断补充表（DOI 10.34970/648456），复用项目既有 HAM v4.0 的完整 seed17 图像清单。网页读取工具不支持 CSV 类型；三条普通下载请求均遇到本机网络限制，获准联网后从官方 S3 下载成功，工具报告三文件下载命令共 5.79 秒。没有读取盲测数据。 [ISIC 原始发布与许可](https://api.isic-archive.com/doi/milk10k/)

本方向目录下复现。下载到本轮原始目录，重跑请换新的编号。缺少 HAM 本地清单时，可先按主线 README 通过官方入口重建同版本划分。

```powershell
$src = 'outputs/20261118/E00-metadata-01'
$base = 'https://isic-archive.s3.amazonaws.com/dois/10.34970-648456'
New-Item -ItemType Directory -Path $src -ErrorAction Stop
Invoke-WebRequest -UseBasicParsing "$base/milk10k.csv" -OutFile "$src/milk10k.csv"
Invoke-WebRequest -UseBasicParsing "$base/supplements/training_input.csv" -OutFile "$src/training_input.csv"
Invoke-WebRequest -UseBasicParsing "$base/supplements/training_supp.csv" -OutFile "$src/training_supp.csv"
..\..\.venv\Scripts\python.exe audit_metadata.py --source $src --ham-split ../medical-vlm-hierarchy/outputs/20261117/E00-ham-metadata-01/split_seed17.csv --output outputs/20261118/E00-pairs-01
```

**输出与基线。** 首次聚合耗时 0.117232 秒，包括 CSV 读取和哈希计算。完整结果在 `outputs/20261118/E00-pairs-01/summary.json`，同份[聚合摘要](reports/E00-pairs-01.json)随仓库保存。三表各 10,480 行、10,480 个不同图号，图号集合完全一致。两份带配对列的表逐行键集合也完全一致。5,240/5,240 个病灶恰好一张临床近照及一张皮肤镜，符合发行方公布的规模，图像行许可均为 CC-BY-NC。

**限制与负面结果。** 三张表都缺患者标识、采集中心 ID、显式旧图号映射列。输入中的 `site` 为解剖部位。与 HAM 的 10,015 个当前图号确切相同的有 0 个。图像是否改名重发、近重复和预训练重叠仍待核查。此次没有模型基线，净纠错率、召回率和 GPU 耗时均未测。盲测标签和患者独立评价尚不可用于这次配对研究。 [官方挑战任务](https://challenge.isic-archive.com/landing/milk10k/)
