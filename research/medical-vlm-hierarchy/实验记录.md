## 2026-11-17 E00 HAM 官方元数据与病灶级划分

- 目的：核实实际数据规模和长尾校准数量，生成不跨病灶的开发划分。
- 输入：Harvard 官方 DOI `10.7910/DVN/DBW86T`，API 当前公开 v4.0；metadata 文件 ID 4338392，下载格式 original。条款为 CC BY-NC 4.0，保存在原始 API JSON 中。
- 命令：`python prepare_ham.py --output outputs/20261117/E00-ham-metadata-01`。
- 输出目录：`outputs/20261117/E00-ham-metadata-01/`；含原始元数据、原站发布信息、三套 split CSV、audit.json。
- 实测：4.038 秒；metadata 690,218 字节。SHA256 `de17ec44cb25ea9c3f6378ba18d69224c740afd62e86ec2edc6a894d6aa663d3`；实际 MD5 `8f85fb1aa29d80a2797247e434deb79d`，与 API 声明一致。本次工具保留 API 原始 checksum 字段，不以未下载 ZIP 的校验和冒充已验证图像。
- 实际规模：10,015 图像，7,470 个病灶。图像类别数：akiec 327、bcc 514、bkl 1,099、df 115、mel 1,113、nv 6,705、vasc 142。元数据无 patient_id。
- 参数：种子 17/29/43；病灶组内单一诊断；按诊断分层分配 40/10/25/25%，最大余数法。主分析每病灶选 image_id 字典序最小图像，与标签无关。
- 三套划分各为 train 2,988、dev 746、calibration 1,869、test 1,867 病灶；每组仅属于一个 split。不是图像随机拆分。
- 代表图校准分布：nv 1,351，bkl 182，mel 154，bcc 82，akiec 57，vasc 25，df 18。test 的 df 同为 18。该计数支持“小类别不足以轻易做严格风险保证”的研究动机，不证明任何方法优越。
- 基线：无已有模型实测；不报告 AUROC、U 或覆盖提升。历史缓存未复用，全部是首次元数据获取和划分。
- 未完成：原图下载、逐图哈希、近重复、患者级独立性、正式树审查、PAD 数据获取、特征提取。当前只可称元数据与分组审计通过，E00 整体尚未完成。原图内容去重后可能需要升级 split 版本，当前不锁定为论文最终划分。
