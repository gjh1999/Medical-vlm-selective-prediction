# 实验记录模板

首次实际实验后，在本目录建立 `实验记录.md`，按日期追加以下结构。规划与未执行事项不作为实测结果。

## 日期与实验编号

- 状态：完成 / 失败 / 无改善 / 中断。
- 目的与对应假设：
- 基线 run 与本次唯一改变：
- 数据来源、版本、许可、样本数与独立组数：
- split、去重 manifest、类别树版本及哈希：
- 模型、revision、预训练来源与重叠审计状态：
- 环境：硬件、系统、Python、PyTorch、CUDA 和关键依赖版本。
- 参数、种子、提示模板、校准预算与风险要求：
- 完整复现命令：填写实际运行命令，不抄尚未实现的接口。
- 输出目录：每次独立目录。
- 缓存复用：cache_id、原始生成 run；若未复用填无。
- 实测：逐类 n/k、覆盖、风险、上界、U、计算耗时与峰值显存；未测项明确写未测。
- 对比：同 split、同数据预算、同风险要求与基线的差值和不确定性。
- 失败/边界情况：无可行策略、缺类、零接受、协议例外与中断原因。
- 结论：支持/反对/不足以判断哪项假设。
- 下一步与未解决问题：

每轮同时保留原始预测与机器可读指标，避免只保留截图或最好的一次结果。测试集被用于选方案时必须标明，该结果改为开发结果并重新设计最终验证。
