# 研究计划 v0.1

日期：2026-11-17；状态：探索草案。来源和竞争关系见[文献差异表](文献差异表.md)。

## 1. 收窄问题

暂定题目：**有噪声提示下交互医学分割的风险受控停止**。

相同图像、模型和提示预算下，轻微点击偏移或一次错误提示可能造成稳定但错误的掩码。我们想检验：使用当前模型输出、提示一致性和历史轨迹，是否可以在停止样本的失败率受限时，提高自动完成比例或减少人工点击。

H1：提示扰动响应与历史变化在基础输出置信度之外提供失败预测信息。H2：整条轨迹校准比未经校准的逐轮阈值更能控制错误停止。H3：收益在改变模拟用户策略后仍存在。这些均未被实验支持；H2 的可行性不代表方法新颖性。

## 2. 任务与风险定义

每例最多 T=5 次人工点击；第 t 次输入后得到 mask M_t。停止策略只能看图像、已提供的提示、预测和历史，不能看 GT 或真实 Dice。输出三种状态：继续、自动完成、预算耗尽转人工。最后一轮只有通过停止规则才算自动完成；超预算转人工不能伪装为成功停止。

开发用合格阈值 q=0.85 Dice，敏感性阈值 0.80/0.90；这些是方法研究参数，不是临床验收标准。令 A 表示在预算内自动完成，F 表示最终自动完成掩码 Dice<q。

- 主风险 R_sel=P(F|A)，自动完成样本内的失败率，目标 α=0.05。
- 自动完成覆盖 C=P(A)，必须与主风险同时报告。没有自动完成样本时 R_sel 未定义，不能写 0。
- 辅助总体错误停止风险 P(A 且 F)，不得与 R_sel 混用。
- 报告平均人工点击（转人工病例计满 T）、模型调用次数、GPU 延迟及转人工率；转人工后修图耗时未观测，不算作零。

统计候选：在 dev 上冻结信号、模拟器、K 个阈值策略和选优规则；每个候选先完整回放独立 calibration 轨迹。对每策略自动完成病例中的失败数，用单侧精确二项上界、每策略 δ/K 做同时控制，再在通过者中按预设效用选一个；最终 test 只评估一次。无候选通过则回退为全部转人工。

这依赖独立同分布的校准单位和固定策略族。每例多轮、多个随机种子不是独立病例；主分析每独立组固定一个代表图和一个预先抽样用户轨迹，额外种子只做敏感性分析。若采用组内最坏情况，需另立组级风险定义。域外/用户行为变化时保证不自动成立，单列压力测试或重新校准，不声称任意分布鲁棒。

避免逐轮独立阈值的重复检验问题：将“首次满足阈值时停止”的整个规则视为一个固定策略并在完整轨迹上评估；不把每一步的 95% 置信度误写成整条路径 95%。条件失败率随阈值不必单调，因此不依赖未经证明的单调性搜索。

## 3. 数据与模型

首选 [Kvasir-SEG 官方入口](https://datasets.simula.no/kvasir-seg/)，既有报告记载 1,000 图像和 mask；本轮网页获取超时，尚未下载核验。病例/视频 ID、许可、图像近重复、mask 对齐、是否进入基础模型预训练均必须核实。缺病例 ID 时只能称图像/去重组评估，不能声称患者级保证。

候选按独立组分 dev/calibration/test=20/40/40%，种子 17；29/43 只做预先规定的敏感性分析，不挑最好种子。开发集内如需训练质量预测器再划分内部训练/验证；禁止使用 calibration 调特征。比例会受组规模影响，以实际计数为准。既有 VLM 的 HAM/PAD 分类数据不能直接当成有分割 GT 的数据。

外部模态候选：[ISIC Challenge 官方数据](https://challenge.isic-archive.com/data/)的分割任务，待核查版本、掩码许可、患者/病灶身份和预训练重叠；不同年度不能未经去重当独立外部数据。真实用户验证候选为 ScribblePrompt 作者提供的 MedScribble，必须分别核对原图访问和标注许可。

首个骨干为冻结 ScribblePrompt-UNet；记录 upstream commit、checkpoint SHA256、预处理、分辨率、坐标变换和历史 mask 传递。后续用作者支持的 SAM 版本检验可迁移性。UNet 无可用质量分数时，使用明确的熵/前景置信度代理，并标记其不是校准质量概率。GPU 环境在 RTX 5080 单独验证，不沿用本机 Python 3.14 环境安装模型依赖。

## 4. 提示协议

主实验仅点提示，第一轮一个正点，后续每轮最多一个纠错点；固定相同种子做方法配对。GT 只允许用于离线模拟用户和评价，不能作为停止器输入。首次点和纠错点来自 GT 的结果必须标为模拟交互。

| 条件 | 开发草案 | 约束 |
| --- | --- | --- |
| 理想用户 | 最大错误区域内部选点 | 仅参考上界，不代表实际医生 |
| 随机用户 | 在错误像素集合内均匀采样 | 检验是否依赖单一中心点击模拟器 |
| 偏移 | 原图坐标高斯偏移，σ=0/0.01/0.03 × 图像对角线，越界截断 | 保留原提示标签，跨边界视为真实噪声；报告实际像素位移 |
| 错误标签 | 点击标签翻转概率 0/0.05/0.10 | 分析首点错误与后续错误，不能保证错误点总能被恢复 |
| 漏点 | 概率 0/0.10/0.20 不提交本轮提示 | 未提交仍计一次交互尝试，避免隐性省成本；与实际提交数分列 |

首轮做单因素，不先做大规模笛卡尔积；组合噪声留作压力测试。训练/开发、校准和测试的噪声分布必须明确区分。先固定 1/3/5 次提示绘制质量轨迹，再比较停止决策。

额外一致性 probe 用已有提示做小位移，不调用 GT 改正其语义，K_probe=0/2/4，位移 σ=0.005 × 对角线。probe 跨真实边界的比例仅在离线评估中分析。probe 不冒充免费人工输入；新增推理全部计入成本。初期只生成评分，不修改主轨迹或输出 mask，才能公平回放停止器。

## 5. 基线与消融

| 方法 | 作用 |
| --- | --- |
| 固定 1/3/5 次后结束 | 原始质量与成本参考；未经验证不能称可靠自动完成 |
| 基础置信度阈值 | 最简单的停止基线；阈值在 dev 固定 |
| 相邻 mask 稳定性阈值 | 检验“稳定但错误”的失效 |
| prompt probe 分歧阈值 | 对照已有不确定性路线 |
| 置信度 + 完整轨迹校准 | 必须击败的统计基线，排除收益仅来自校准 |
| 置信度 + 历史 + probe + 相同校准 | 候选方法，分别去掉每类信号并对齐推理预算 |
| GT 首次达标即停 | 离线 oracle，只作参考，不参与可部署优劣排名 |

AIES 和 SPRC-CB 优先核查可复现性。无法得到官方实现/必要细节时，明确写未复现，不能用自编近似结果冒充原方法。SAM-U 等框提示方法只在统一框提示辅助实验中比较，避免提示信息量不公平。

指标：每轮 Dice/IoU、Dice<0.5 的灾难失败率、R_sel 与单侧上界、coverage、平均点击/调用/延迟、NoC@0.85 及 T 内未达标率。未达标样本不能从 NoC 平均中删除。风险-覆盖曲线用于描述，test 上不能据曲线挑阈值再报保证。置信区间以独立组配对重采样，多种子不扩充病例数。

## 6. 两周最小验证与退出条件

1. E00：文献、数据/许可/预训练来源核查、样本量可行性。当前仅完成首轮文献和样本量计算。
2. E01：50 张开发图的冻结模型冒烟；检查坐标、mask 二值化和多轮状态，保存全部失败。不得提前读取测试指标。
3. E02：开发集提示扰动轨迹；确认稳定但错误是否普遍，比较基础置信度与 probe，计算新增成本。
4. E03：固定最多 20 个候选策略，在独立 calibration 上评估并冻结停止规则，test 一次性评价。样本数不足或全部转人工也如实记录。
5. E04：换模拟器/模态并做真实提示子集核验；分布改变后的结果单列。

计划性继续门槛：在同等风险上界约束下，相对“置信度 + 相同校准”覆盖提高至少 5 个百分点，或覆盖下降不超过 2 个百分点时平均点击减少至少 10%；GPU 延迟不超过其两倍，并在第二种模拟用户下保持收益方向。门槛不是已有结果或统计显著性标准，需同时报告不确定性。

若 probe 只在单个模拟器有效、结果依赖 GT 框/GT 筛提示、或校准样本不足导致几乎全拒绝，先停止加网络模块。若仅复现已有一致性评分且没有新可靠性证据，降低为基准/负面结果分析，不强行包装算法创新。8–12GB 等旧预算仅是估计，本轮没有实测显存或训练时间。
