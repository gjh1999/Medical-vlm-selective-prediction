| 项目 | 源码结论 | 实验实现要求 |
| --- | --- | --- |
| 图像 | 灰度 B×1×H×W、值域 [0,1]；官方推荐 128×128 | 彩色 Kvasir 不能直接作为三通道输入；明确灰度转换、尺寸/填充和归一化 |
| 坐标 | 整数 `[x,y]`，正负标签 1/0 | resize/padding 后统一变换并截断；非方形图必须单测，不能混用行列 |
| 上一轮状态 | `mask_input` 接收 logits | 调用 `predict(..., return_logits=True)`；sigmoid 后概率仅用于评分/二值化，不能冒充上一轮 logits |
| 输出质量 | 只有分割输出，没有独立 predicted-IoU 质量头 | 熵/前景置信度只是代理信号，不得称为原生质量概率 |
| 自动缩放 | 文件定义 `rescale_inputs`，但 `predict` 没有调用它 | 不能以为设置了 input_size 就会自动缩放输入或提示 |
| 运行模式 | `predict` 有 no_grad；构造函数未显式 eval | 适配器显式 `model.eval()`；本版网络无 BatchNorm/Dropout，仍固定推理模式 |
| 历史提示 | 点编码形成正负二通道，与图像、框和历史 logits 拼成 5 通道 | 明确累计点击、重复位置和矛盾标签语义；不让 probe 修改主轨迹历史 |
| 依赖与权重 | requirements 只有宽松下限；权重文件名 `ScribblePrompt_unet_v1_nf192_res128.pt` | 原始依赖不是 5080 已验证锁定环境；checkpoint 未下载，哈希未知 |

## MedScribble：有真实提示，但不是大规模独立校准集

[作者数据说明](https://github.com/halleewong/ScribblePrompt/blob/182c44975f77749b559974ce8db558c8bde57788/MedScribble/README.md)描述 14 个任务、64 个图像分割样例、每例 3 位标注者。AbdominalUS、SpineWeb 的图像需另行获取，其他来源提供相应图像/掩码切片。

本轮 Git tree API `truncated=false`，实际列出：56 个 `img.npy`、56 个 `seg.npy`；`scribble_0.npy`、`scribble_1.npy`、`scribble_2.npy` 各 64 个。README 示例写 1/2/3，而实际树是 0/1/2，未来 loader 必须按文件核实，不能照示例猜编号。清单计数不等于数组已下载、配对内容已验证或合法再分发已逐源确认。

14 个目录：ACDC、AbdominalUS、BTCV、CAMUS、CHAOS、HipXRay、OASIS、OCTA500、PAXRay、PanDental、SCD、STARE、SpineWeb、WBC。数据说明为单次涂鸦集合，不能直接当连续纠错轨迹；多标注者也不能算额外独立患者。

决定：保留为后续真实提示一致性验证资源，暂不作为主校准集。即使把全部 64 个样例都视为独立且自动接受，20 策略/5% 风险目标所需的 117 个零失败单位仍不够；真实独立数可能更少。

## 真人点击能回答哪一轮停止问题

2026-11-18 核查 RClicks 的采集协议与发布字段。作者报告五个自然图像数据集共有 185,349 个真人首点，另有 290,195 个真人次点。采集次点时先用 SAM、SimpleClick、RITM 生成候选首轮预测，再依据 GT IoU 挑选满足 0.95 上限的高质量掩码。次点针对其中 8,144 张首轮掩码的错误区域。发布字段可定位图像、目标、模型、首点或正负纠错点、设备和坐标；没有把同一标注者各轮连接为会话的键。论文附录 E.2 Q5–11 可复核字段及轮数。[原始论文 §3.3、表 2、附录 E.2](https://proceedings.neurips.cc/paper_files/paper/2024/file/e6b5bcc872666d37c469e5c5ba723669-Paper-Datasets_and_Benchmarks_Track.pdf)

作者仓库将真人输入示例设为 `--n-clicks=1 --user_inputs`，20 轮示例从点击模型采样。把真人次点移到 ScribblePrompt 自行产生的上一轮掩码，会改变人所看到的错误；跨图或跨标注者拼接点击还会改变轨迹对应的人和目标。此次查核只支持自然图像的真人首点对照，以及在原展示掩码上研究条件纠错点位置。医学五轮自动停止效果和医生的工作耗时仍待测。[作者复现入口](https://github.com/emb-ai/rclicks#real-user-evaluation-example)

**具体对照**。可先用作者列出的 GrabCut 50 张图，每个目标按固定种子抽一个真人首点，并与同图 GT 内最大距离点配对。固定同一骨干和开发集上预定的置信度阈值，每条支路恰好推理一次，报告首轮 Dice 配对差、被接受图数与其中失败数。这是查询自然图像首点偏移影响的低成本补充。50 个目标即使全接受且零失败，仍低于既有 5% 风险门槛所需的 59 个（单策略）或 117 个（20 策略）独立接受单位。若停止改进只在中心点存在，撤回对真人首点的泛化主张。正式主线仍须在有独立分组的医学图像上，以相同校准的廉价置信度策略为对照，按研究计划评价覆盖、点击和延迟；缺少同一模型的真人连续轨迹时，医学多轮结论限于已测试的模拟器。[数据清单](https://github.com/emb-ai/rclicks#prepare-datasets--models-checkpoints)
