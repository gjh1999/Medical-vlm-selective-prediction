# 本子项目工作约定

- 开始前阅读 README.md、研究计划.md、文献与数据核对.md、实验记录.md。
- 遵守用户全局实验记录与 Git 同步规则。当前子项目属于 MCCAI 根仓库，不单独初始化 Git 或重复登记自动备份。
- 真实医学评价与合成机制实验严格区分；不得从合成收益推出医学有效性。
- source-only、target-normal、target-labeled 的数据预算分别报告。拟合归一化与共形校准使用独立组，测试标签不用于选择。
- 每次实验用新的 outputs 子目录，记录无改善和失败；文档保留摘要，原图/权重/样本缓存不提交。
- 本机仅 CPU 准备，正式 GPU 为家中 RTX 5080，未实测的显存和依赖兼容性不可承诺。
