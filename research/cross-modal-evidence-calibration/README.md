# 跨模态异常检测中的证据校准

2026-11-17 建立，作为医学 VLM 层级拒识之外的并行研究子项目。当前目录由 MCCAI 根仓库管理，不另建嵌套 Git 仓库；根仓库已登记全局 17:00 自动备份。

首轮状态：5 项软件测试通过；3 场景 × 3 种子 × 4 基线合成机制实验完成。单路偏移下源阈值误报率 49.43%，目标正常校准与归一化后为 4.42%；这是人为分数实验，尚未验证医学有效性。全部对照和无改善项见实验记录。

研究问题：在冻结视觉语言模型、目标测试标签不可见的条件下，如何区分异常病灶证据与正常组织造成的高响应，并减少跨医学影像模态迁移时的误报？这里“跨模态”指 MRI、CT、OCT 等影像域迁移，图文证据来自 VLM，不假设同一患者具有配对多模态图像。

2026-11-18 核查发现，MVFA 公开训练代码留出 OCT2017 后仍使用 RESC，并按目标测试分数选存 checkpoint。严格零目标访问对照暂缓使用该训练路径。OCT2017 的 16 张正常支持图对应 15 个随机患者 ID，16 张异常支持图对应 13 个。完整证据及替代基线见[准入核查](文献与数据核对.md)与[实验记录](实验记录.md)。

- [研究计划](研究计划.md)：范围、对照、统计边界、继续与停止条件。
- [文献与数据核对](文献与数据核对.md)：本次已查证来源及尚未完成的审计。
- [实验记录](实验记录.md)：包括合成机制实验与失败/无改善结果。
- `calibration.py`：仅含基础 z-score 融合、正常样本共形 p 值和指标。
- `run_synthetic.py`：标准库 CPU 合成实验，不读取医学影像，不模拟 GPU 性能。

在本目录执行，无第三方依赖（本轮 Python 3.14.7）：

```powershell
python -m unittest -v test_calibration.py
python run_synthetic.py --output outputs/20261117/E01-synthetic-01
```

输出路径必须不存在；重跑用新的编号。每次保存配置、逐种子指标、环境、源码 SHA256 和耗时。`outputs/` 不进入 Git，实验摘要随文档提交。当前尚无真实医学模型结果，不能根据合成指标宣称有效或新颖。
