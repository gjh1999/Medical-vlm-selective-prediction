# 跨模态医学异常证据校准：启动协议 v0.1

日期：2026-11-17。探索阶段，不是已确认的创新点或论文结果。

## 1 问题收窄

继承选题报告的“正常组织纹理与文本语义错配导致未见模态误报”假设。研究冻结检测器的图像文本异常分数、局部异常响应、正常参考距离和提示分歧能否提供互补信息。图文语义与局部/参考分数是候选证据，不默认统计独立，也不把 softmax 数值当校准概率。

DeCal 已研究异质证据分流、校准与可靠性融合，因此“两个分数分别校准再融合”本身不足以成为贡献。优先研究医学正常组织误报、目标正常样本预算与迁移失效边界；能否形成方法贡献仍待真实数据验证。

## 2 必须分开的三种访问权限

| 协议 | 可使用的目标域数据 | 阈值与参数 | 可声称内容 |
| --- | --- | --- | --- |
| Z：目标零访问 | 无 | 仅源域训练/dev/calibration；固定后进目标测试 | 零目标数据迁移；没有目标域误报保证 |
| N：目标正常校准 | 独立且确认正常的参考和校准患者 | reference 拟合归一化；calibration 计算阈值，两者分离 | 目标正常样本适配，不称严格零样本 |
| L：少量目标有标注 | 独立正常和异常 dev/calibration 患者 | 可拟合温度/融合、用异常校准选敏感度阈值 | 少样本监督上界，不能与 Z 不加区分比较 |

影像模态必须按 MRI/CT/OCT 等分组留出；两个 OCT 数据集之间转移只是跨数据集，不能称留一模态。源域开发集选择所有超参数，源域校准集不重复用于选择融合规则。目标测试标签仅最终评价。患者、体积、病理切片及近重复组不能跨集合；来源身份不明时只能做受限复现，不声称患者独立泛化。

## 3 基线与候选

先固定 MVFA 官方权重及对应留出域（训练来源核实后才可采用），AA-CLIP 作为第二骨干；若官方权重来源不满足留出条件，则单独标为预训练复现或重新训练，不借用 all-datasets 权重宣称未见域。

同一骨干/缓存/样本预算下依次比较：原始分数；提示集成；局部平滑；温度缩放（仅有合法二分类标签时）；正常参考 z-score 均值融合；单一最终分数共形阈值；候选可靠性融合。温度对二分类单分数的正单调变换不改变排序，不期望它直接提高 AUROC。只观察 ECE 下降不能证明误报排序改善。

候选工作假设：局部病灶支持与图文提示分歧可能区分“正常但高响应”和真正异常。必须比较相同正常参考预算的简单 z-score/均值/最大值融合，并消融参考距离、提示分歧、局部证据、模态标签及随机伪分歧。共同偏置或真正异常的高分歧可能使抑制策略伤害敏感度，需主动记录。

## 4 阈值与指标

固定异常分数 s，独立正常校准集大小 n，使用

`p(x) = (1 + #{i: s_i >= s(x)}) / (n+1)`，`p <= alpha` 时报警。

该 p 值不是异常概率。固定评分函数且正常校准/新正常样本可交换时，提供正常样本的边际误报控制；不是每次实现的 FPR 必然低于 alpha，不是 FDR 保证，不保证每种疾病/患者亚组，也不覆盖源目标分布变化。同患者多切片不能按独立样本计 n；像素相关性不能直接套用逐像素保证。n=9 时最小 p=0.1，不能实现 alpha=0.05 的报警；alpha=0.01 至少需 n=99 才有非空拒绝域，仍不代表检验功效足够。

主指标：冻结正常阈值后的 FPR、敏感度；同时报告图像 AUROC、非插值 AP（作为 PR 汇总指标）、异常比例、每模态与 macro 结果。另在 L 协议用独立异常校准数据选择 95% 敏感度阈值，报告测试实际敏感度和 FPR；测试 ROC 上的 FPR@95%TPR 只能作为描述性指标单列，不是可部署阈值。

有真实 mask 才报告像素 AUROC/AUPRO；无 mask 不生成虚假定位评价。正式实验按患者配对 bootstrap 报告区间；少患者明确不稳定。校准预算计划 19/49/99/199 个独立正常单位，拟合 reference 预算另列且各方法相同，不把共计 398 个样本写成 199-shot。

## 5 本轮 E01 与后续决策

本轮先运行完全合成分数实验：两路高斯相关证据、3 个固定种子 17/29/43；reference 和 calibration 各 199 个正常样本，测试正常/异常各 2000。alpha=0.05。三场景为同分布、单路尺度与位置偏移、两路共同位置偏移。异常信号人为设为两路分别 +0.5/+2.0，因此结果由构造机制驱动，不是医学真实性证据。

四基线为 source_raw/source_z/target_raw/target_z，分别分离源/目标数据访问与归一化贡献。target 方法使用 398 个额外正常样本预算（raw 未使用其中 reference 部分）；所有方法使用相同测试样本。合成种子标准差只是离散程度，不能冒充临床置信区间。E01 不选择新方法超参数，不用于决定真实数据胜负。

第 1 周：完成近邻论文全文差异审查、BMAD 分项许可/患者分组审计，跑通一个骨干的小批次证据导出。第 2 周：至少两个医学影像模态，固定分割做 Z/N/L 对照；无法核实患者或权重泄漏时先修协议，不堆新模块。

继续标准：真实数据同等访问预算下，至少两个留出模态稳定降低 FPR，且敏感度下降不超过预设 2 个百分点；以患者配对区间检查稳定性，不以某个种子胜出定论。正式测试前冻结该准则、样本量、方法候选数及参数。若仅优于 source_raw、不优于 target_raw/target_z，归因于目标数据/基础校准；若去重后消失、只对某提示成立或必须读测试标签则停止该方法方向。两周节点是可行性筛查，不是发表承诺。
