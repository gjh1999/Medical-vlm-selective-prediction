## 目前的研究切口

在固定总标注预算下，新增一个支持样本和修正一个已有支持掩膜，哪种操作更能改善冻结分割器的低分位表现？先测质量、覆盖、多样性之间是否存在稳定的交互，再决定是否设计动态分配算法。该问题的新颖性尚待进一步查新，当前不声称首创。

必须分别记账：已标注池大小 `L`、单次上下文大小 `K`、累计人工成本 `B`。从 100 张有标签样本中检索 4 张，只能说 `K=4`，不能说只花了 4 张标注。

## 已可运行

以下命令从本目录执行，仅需 Python 标准库，不安装模型或下载医疗原图。

```powershell
python preflight.py --network --output outputs/20261117/E00-source-audit-03
```

每次换用新输出目录；脚本拒绝覆盖。去掉 `--network` 可只检查环境。网络步骤失败会写入 `audit.json` 并返回非零退出码，部分成功不能当成整体通过。GitHub commit API 当前解析的版本会写入报告，再按该 SHA 获取文件；它不是自动复现历史固定版本的下载器。

本机检查使用系统 Python 3.14.7，没有 torch/numpy/Pillow，GPU 为 GT 710 2GB。原研究记录提到家中 RTX 5080，目标机本轮未访问、未验证。正式环境先采用独立 Python 3.11 环境作为候选，实际兼容性验证后才锁定依赖；不沿用无版本约束的上游 requirements 作为可复现环境。
